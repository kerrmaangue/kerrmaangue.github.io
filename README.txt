Logos used on the Skills tab are inlined into index.html as SVG paths.

Sources (all bundled with the Material for MkDocs icon packs):
  - Microsoft 365 apps, Salesforce, SharePoint, OneDrive, PDF: Material Design Icons (Apache 2.0)
  - Zoom, Gmail, Google Calendar/Meet/Drive/Docs/Sheets: Simple Icons (CC0)

Procore, Bluebeam Revu, Dodge IRIS / DF Manager and Smartsheet show a monogram tile because no
logo file was available. To use an official mark, replace the <span class="mono"> in that tile
with the company's SVG (class="logo").
