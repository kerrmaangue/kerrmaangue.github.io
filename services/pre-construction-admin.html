Pre-Construction Admin & Planning

Project setup, document control and planning support so the pre-construction phase runs on one clean record.

For: General Contractors, Owners, AEC Firms

Pre-construction workflow

  1. Kickoff: confirm the project, contacts and deliverables.
  2. Set up folder structure, naming rules and trackers.
  3. Load drawings, specs and contracts into the document register.
  4. Each week: log changes, send minutes, chase open actions.
  5. Closeout: archive a complete, indexed project record.

Pain points solved

  • Files scattered across inboxes and drives
  • No one sure which drawing revision is current
  • Meeting actions that never get followed up
  • PMs losing hours to filing instead of decisions

Logs and templates I maintain

  • Document register
  • Meeting minutes and action log
  • Planning calendar
  • Weekly dashboard summary
