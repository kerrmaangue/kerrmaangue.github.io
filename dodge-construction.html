Background

Projects start in public documents long before bidding. The work was finding them in those documents, then making each record complete, verified and correct.

Scope & deliverables

Responsibilities

  • Tracked capital improvement plans (CIPs)
  • Managed Dodge Reports (V1s)
  • Logged RFIs and submittals
  • Verified A/E and GC factors for each project
  • Deduplicated project records
  • Managed source communications

Estimating matrix

  • Square-foot rates ($30/SF barns, $100/SF hangars)
  • Unit-based valuation for boilers and AHUs
  • DOT mile-marker linear costing formulas
  • Multi-tab rules (GB, Engr, DOT, B-Items, C-Items)

Core takeaways

  • Found projects early by following CIPs, State Revolving Funds, bond referendums and municipal agendas
  • Set up Dodge Reports (V1s), logged RFIs and merged duplicate records so each project appears once
  • Built and maintained one consistent code price method for valuing projects from public data
